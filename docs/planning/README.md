# Project planning archive

This directory preserves the original Meowfolio discovery and implementation materials. Each of the seven files was copied **without rewriting its contents**, then removed from the former `devpost/` folder after verification. Git history retains the earlier locations.

These files document decisions made while building the project; they are **not** a Devpost submission or a list of official Hacktoberfest entry requirements. In particular, the early product concept considered automatic familiar-cat suggestions, but the production policy ultimately disabled them after evaluation.

| Document | Purpose |
| --- | --- |
| [scope.md](scope.md) / [scope.html](scope.html) | Product idea and early scope review |
| [prd.md](prd.md) / [prd.html](prd.html) | Product requirements and user journeys |
| [spec.md](spec.md) / [spec.html](spec.html) | Original technical design and review snapshot |
| [checklist.md](checklist.md) | Historical build slices, CI evidence, and outstanding physical Android checks |

For current capabilities, see the [project README](../../README.md). For actual entry information, see [Touch Grass submission notes](../TOUCH_GRASS_SUBMISSION.md). For the Android hands-on protocol, see [ANDROID_FIELD_TEST.md](../ANDROID_FIELD_TEST.md).

> Note: This archive includes uncompleted historical checkpoints. Do not mark physical Android testing as passed merely because the CI suite is green.
